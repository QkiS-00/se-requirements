# ER-модель: бібліотека з кількома філіями

## Домен
Обрав домен «Бібліотека». Це мережа з кількох філій, де читачі беруть книги додому.

## Чому цей домен
Він знайомий, у ньому є зрозумілі сутності й чіткі зв'язки. Також у ньому є цікаве питання: книга й фізичний примірник цієї книги — це різні речі.

## Про що модель
У моделі описано:
- читачів, які оформлюють видачі;
- книги (назва, автор, рік видання);
- примірники книг зі станом (новий, потертий, втрачений);
- філії бібліотеки, де зберігаються примірники;
- видачі, у яких фіксуються дата видачі, термін і дата повернення.
