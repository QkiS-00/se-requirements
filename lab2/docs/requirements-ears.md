# Функціональні вимоги (EARS)

Вимоги стосуються лише UC-1 «Знайти книгу у філіях» та його сценаріїв S1–S5. Правило наявності примірника описане в spec.md.

- **FR-1.** КОЛИ Шукач книги надсилає непорожній запит, система ПОВИННА знайти всі Книги, у яких `назва` або `автор` містить текст запиту (без урахування регістру). (S1, S2)
- **FR-2.** КОЛИ знайдено хоча б одну Книгу, система ПОВИННА показати для кожної `назва`, `автор` і `рік_видання`. (S1)
- **FR-3.** КОЛИ показується знайдена Книга, система ПОВИННА показати для кожної Бібліотеки, у якій є Примірники цієї Книги, кількість вільних Примірників, зокрема 0. (S1, S2)
- **FR-4.** ЯКЩО для знайденої Книги кількість вільних Примірників дорівнює 0 в усіх Бібліотеках, ТО система ПОВИННА додатково показати повідомлення «Вільних примірників немає». (S2)
- **FR-5.** ЯКЩО за запитом не знайдено жодної Книги, ТО система ПОВИННА показати повідомлення «Нічого не знайдено» і запропонувати змінити запит. (S3)
- **FR-6.** ЯКЩО запит порожній або складається лише з пробілів, ТО система ПОВИННА показати повідомлення «Заповніть запит» і не показувати результатів пошуку. (S4)
- **FR-7.** КОЛИ Шукач книги обирає Бібліотеку з результатів, система ПОВИННА показати `назва_філії` та `адреса` цієї Бібліотеки. (S5)
