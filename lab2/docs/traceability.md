# Матриця трасування: вимога ↔ сценарій / UC

| Вимога | S1 | S2 | S3 | S4 | S5 | UC |
|--------|----|----|----|----|----|----|
| FR-1   | ✓  | ✓  |    |    |    | UC-1 |
| FR-2   | ✓  |    |    |    |    | UC-1 |
| FR-3   | ✓  | ✓  |    |    |    | UC-1, UC-3 |
| FR-4   |    | ✓  |    |    |    | UC-1, UC-3 |
| FR-5   |    |    | ✓  |    |    | UC-1 |
| FR-6   |    |    |    | ✓  |    | UC-1 |
| FR-7   |    |    |    |    | ✓  | UC-2 |

## Перевірка покриття
- Кожна функціональна вимога покрита хоча б одним сценарієм: непокритих вимог немає.
- Кожен сценарій перевіряє хоча б одну вимогу: S1 (FR-1, 2, 3), S2 (FR-1, 3, 4), S3 (FR-5), S4 (FR-6), S5 (FR-7).
- UC-3 не має окремого сценарію, бо входить до UC-1 (`include`): його перевіряють S1 і S2 через FR-3 та FR-4.
- UC-2 покритий сценарієм S5 і вимогою FR-7.
- НФВ (NFR-1..NFR-7) у матриці не беруть участі за умовою завдання: вони стосуються якості, а не окремого сценарію.
